## 概览 {#overview}

| 名称 | 网址 | 用途 |
| --- | --- | --- |
| 信息门户 | [https://my.bupt.edu.cn](https://my.bupt.edu.cn) | 查看通知、公示信息、部分资源入口 |
| 教务系统 | [https://jwc.bupt.edu.cn/](https://jwc.bupt.edu.cn/) | 本科教学相关事务，选课入口、课程及成绩查看入口 |
| 云邮教学空间 | [https://ucloud.bupt.edu.cn/](https://ucloud.bupt.edu.cn/) | 查询老师上传的PPT等、课程提交作业 |
| 北邮邮箱 | [https://mail.bupt.edu.cn/](https://mail.bupt.edu.cn/) | 北邮人自己的邮箱，可在部分软件中申请教育优惠，例如 PyCharm 等 |
| 图书馆 | [https://lib.bupt.edu.cn/](https://lib.bupt.edu.cn/) | 图书信息一键查询、查看论文 |
| 学工系统 | [http://stu.bupt.edu.cn/](http://stu.bupt.edu.cn/) | 学生工作管理服务 |
| Web VPN | [https://webvpn.bupt.edu.cn/login](https://webvpn.bupt.edu.cn/login) | 在非校园网环境下访问校内网站 |
| Atrust VPN | [https://vpn.bupt.edu.cn](https://vpn.bupt.edu.cn) | 作为 Web VPN 的替代，需要安装客户端且与其他 VPN 冲突 |
| 北邮人BT | [https://byr.pt](https://byr.pt) | 种子搜索、下载各种资源 |
| 北邮人论坛 | [https://bbs.byr.cn](https://bbs.byr.cn) | 北邮人论坛 |

注：1.部分网站如信息门户、教务系统等，需要使用学校内部网络或者使用VPN才能访问。北邮人 BT 只有使用IPv6才能访问。

2.Web VPN为微信扫码登录。Atrust VPN 通过动态口令登录。在北邮企业微信或微信-北邮企业号中，选择校园网-自服务，可看到每30秒生成一次的六位数字，即为当次VPN登录的动态口令。详细使用方法见北京邮电大学信息化技术中心官网-入校VPN部分。
